# Original Pookie artwork

These six illustrations are the creator's original brand assets, The source PNGs are unchanged. Next.js serves optimized display sizes.

Do not delete, redraw, recolor, or replace these characters as part of an interface cleanup. Build the interface around them. The running, resting, planning, check-in, relief, and tired poses express the product's personality and should remain available.

The Apple Watch prototype adds separate `pookie-watch-check-v1.png` and `pookie-watch-run-v1.png` illustrations generated from the original running reference. The originals are unchanged. See [watch-prompts.md](watch-prompts.md) for the exact built-in image-generation prompts and usage notes.
